cookie Cookies & Browser Storage

We use essential cookies needed for authentication and OAuth security, plus a browser preference for your cookie choice. First-party AuthSys pages use the server-side HttpOnly session cookie; they do not store bearer tokens in browser storage. We do not sell personal data or use third-party advertising cookies.

Cookie Type Name Duration Required
Server session connect.sid 1 hour Essential
Privacy choice cookieConsent 365 days Essential
Interface preferences localStorage theme/language/cache Until cleared Optional

The web client may use localStorage for non-authentication preferences, a small profile/activity cache, and the cookie-banner choice. These values are not credentials and are not third-party advertising trackers. The available choices are Accept all and Reject non-essential; rejecting non-essential items does not disable the essential login session.

info
OAuth state and PKCE values are handled as short-lived server-side authorization data; they are not used as persistent tracking cookies.

security Security

We implement industry-standard security measures:

  • 🔒 HTTPS encryption for data in transit
  • 🔑 bcrypt password hashing (salt rounds: 10)
  • 🛡️ HttpOnly sessions for first-party pages; RS256 signing and JWKS for OAuth/OIDC tokens
  • ⏱️ Rate limiting on authentication endpoints
  • 🚫 Token blacklisting and grant revocation on logout/revoke actions
  • ✅ PKCE for OAuth 2.0
