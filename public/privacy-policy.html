settings How We Use Your Data / วัตถุประสงค์การใช้ข้อมูล

เราใช้ข้อมูลของท่านตามวัตถุประสงค์ที่ได้รับความยินยอม หรือมีฐานทางกฎหมายรองรับเท่านั้น

verified

วัตถุประสงค์ที่จำเป็น (Essential)

สัญญา / Contract
  • ให้บริการระบบยืนยันตัวตน (Authentication)
  • สร้างและจัดการบัญชีผู้ใช้
  • ส่งอีเมลที่เกี่ยวข้องกับบัญชี เช่น รีเซ็ตรหัสผ่าน
  • ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
analytics

วัตถุประสงค์เพิ่มเติม (Analytics)

ความยินยอม / Consent
  • วิเคราะห์รูปแบบการใช้งานเพื่อปรับปรุงบริการ
  • เก็บสถิติการเข้าสู่ระบบ

ท่านสามารถถอนความยินยอมได้ทุกเวลา โดยไม่กระทบต่อการใช้บริการหลัก

security Security

We implement industry-standard security measures:

  • 🔒 HTTPS encryption for data in transit
  • 🔑 bcrypt password hashing (salt rounds: 10)
  • 🛡️ JWT token signing (HS256)
  • ⏱️ Rate limiting on authentication endpoints
  • 🚫 Token blacklisting on logout
  • ✅ PKCE for OAuth 2.0
